# soe-investment-risk-control-writing-skill

国资公司投资风控材料写作与评审 Skill —— 一套面向国资公司（产业投资集团）的材料质量标准、写作方法论和评审框架，可直接作为 Claude Code Skill 使用。

> **当前版本：v1.1.0** ｜ 详见 [CHANGELOG.md](CHANGELOG.md)

## 这是什么

本 Skill 解决的核心问题：**国资公司的材料（尽调报告、领导汇报、政府请示、风控意见等）如何写得让领导看得懂、能决策、风险说得清、建议能落地。**

## v1.1.0 升级要点（2026-06-12）

基于 7 份评审案例卡的系统性归纳，对评审 Skill 进行模块化加固——框架不变（八维度评分保留），但在 SOP 前后各加一道卡口，并为投资类、国资公文类材料加入专项校验清单。

新增 6 个模块：

1. **第〇步：四问定位** —— 进入八维度评分前先问"任务性质 / 读者关系 / 领导提问预判 / 论证逻辑"
2. **三道红线自检** —— 用词定性 / 请示担当 / 风险分寸
3. **投资类财务四项必查** —— 折旧 / 财务费用 / 所得税 / 数据常识对标
4. **R 级重构** —— A/B/C/D 之外新增 R 级，处理"框架本身就不对"的材料
5. **读者关系四分对照表** —— 完全陌生 / 知道但不参与 / 知道并推动 / 直接决策参与
6. **加减法自检 + 正向确认** —— 防止"只扣分不加分"和"加法偏好"

## 核心方法论

### 一句话标准

> 让对方在不依赖口头补充的情况下，看懂事项、理解风险、形成判断、安排动作。

### 八项质量维度（满分 100）

| 维度 | 分值 | 核心要求 |
|------|------|----------|
| 读者意识 | 15 | 读者从零开始能看懂 |
| 决策支撑 | 20 | 明确回答核心决策问题 |
| 事实准确 | 15 | 事实有来源，区分事实与判断 |
| 结构逻辑 | 15 | 结论前置，层次递进 |
| 证据链 | 10 | 判断有依据，依据能支撑 |
| 风险表达 | 10 | 风险写具体、写充分、写稳妥 |
| 建议可执行 | 10 | 建议能转化为行动 |
| 公文表达 | 5 | 语言准确、简洁、规范 |

### 写作七步法

1. 拆解写作任务
2. 读取项目资料
3. 判断资料质量
4. 确定写作结构
5. 生成材料提纲
6. 起草正文
7. 自检修改

### 评审四步法（人工+AI 协作）

```
人工评审 → AI评审 → 差异分析（案例卡） → 综合输出
```

### 评审分级（v1.1）

| 等级 | 含义 |
|------|------|
| A | 可直接报送 |
| B | 小幅修改后可报送 |
| C | 需较大修改 |
| D | 暂不建议报送 |
| **R**（v1.1 新增） | **需重构** —— 论证方向错 / 类型错位 / 任务定位不清 / 篇幅文种严重失配 |

## 安装方法

### 方式一：手动安装（推荐）

将本仓库克隆到 Claude Code 的 skills 目录：

  ~/.claude/skills/soe-investment-risk-control-writing-skill

重启 Claude Code 后，Skill 自动生效。
