# soe-investment-risk-control-writing-skill

国资公司投资风控材料写作与评审 Skill —— 一套面向国资公司（产业投资集团）的材料质量标准、写作方法论和评审框架，可直接作为 Claude Code Skill 使用。

> 当前版本：**v1.2.0**（2026-10-12）。变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 这是什么

本 Skill 解决的核心问题：**国资公司的材料（尽调报告、领导汇报、政府请示、风控意见等）如何写得让领导看得懂、能决策、风险说得清、建议能落地。**

## 核心方法论

### 一句话标准

> 让对方在不依赖口头补充的情况下，看懂事项、理解风险、形成判断、安排动作。

### 八项质量维度（满分 100）

| 维度 | 分值 | 核心要求 |
|------|------|----------|
| 读者意识 | 15 | 读者从零开始能看懂 |
| 决策支撑 | 20 | 明确回答核心决策问题 |
| 事实准确 | 15 | 事实有来源，区分事实与判断 |
| 结构逻辑 | 15 | 结论前置，层次递进 |
| 证据链 | 10 | 判断有依据，依据能支撑 |
| 风险表达 | 10 | 风险写具体、写充分、写稳妥 |
| 建议可执行 | 10 | 建议能转化为行动 |
| 公文表达 | 5 | 语言准确、简洁、规范 |

### 写作流程（九步，见 `05`）

```
任务定义 → 观点输入 → Skill 预审 → 证据组织 → 框架确认
  → AI 生成短稿 → Skill 评审 → 人工审核 → 定稿
```

**三条纪律**：没有明确观点，不写正文；没有确认框架，不逐段遣词造句；不为修改文字而修改文字。

### 评审流程（四步法，见 `04`）

```
人工评审 → AI评审 → 差异分析（案例卡） → 综合输出
```

评审前置做**五问定位**（任务性质／读者关系／领导提问预判／论证逻辑／概念框架），并用**卡口触发矩阵**分诊——按材料类型和触发词决定查哪些卡口，而不是每份都全查。

## 关于本 Skill 的局限（重要）

本 Skill 是**检查表，不是判断力**。有几处已知失效模式，使用者应当知道：

1. **重要—次要判断**：AI 天然缺乏重要性判断，它输出的是"我检查了什么"，不是"什么最重要"。主轴自检只是流程约束，须人工兜底。
2. **只能评价材料给定的框架**：材料刻意回避的风险、材料之外的已知问题，AI 看不见，须主动同步。
3. **概念层与立场层需人工确认**：读者关系、概念框架、立场充分性三项含推断成分。
4. **补格子永远滞后案例一格**：完备性靠不断补检查项，详见 `06_待解决问题与候选池.md`。

同样地，`06` 里还如实记录了三条"**仅有 1 例支撑、经判断提前进入**"的规则（待后续案例验证），以及若干被暂时搁置的候选。开源一份会自曝局限的方法，比开源一份看起来无懈可击的方法更有用。
